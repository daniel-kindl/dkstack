# Testing

Use [test-driven development](../tdd/index.md) as the authoritative standard for test-first work, test design, isolation, regression protection and verification.

- Choose tests that prove the specified observable behavior.
- Apply the red-green-refactor process through [TDD loop](../skills/tdd-loop/SKILL.md).
- Use [quality gates](quality-gates.md) when checks fail or cannot run.

Do not duplicate or weaken the testing rules in this file.
