# Quality

## Principles

- Apply clean code, SOLID, DRY, KISS, and YAGNI.
- Prefer readable code over clever code.
- Name things so the purpose is clear without comments.
- Handle errors explicitly.
- Do not suppress warnings or tests to make a change pass.

## Security

- Never expose credentials or personal data.
- Validate inputs at boundaries.
- Prefer the least privilege that works.
