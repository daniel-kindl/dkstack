# Learning

Use these standards when an agent helps a person learn. The goal is independent understanding, not completion of a lesson.

The installable [learn skill](../skills/learn/SKILL.md) provides five modes in one skill: Explore, Learn, Practice, Assess and Review. It works for technical and nontechnical subjects.

## Standards

- [Principles](principles.md): Learner control, evidence and accuracy.
- [Teaching](teaching.md): Hybrid curriculum and adaptive interaction.
- [Assessment](assessment.md): Competency levels and evidence.
- [Retention](retention.md): Recall and later review.
- [Progress](progress.md): Optional portable session state.
- [Scenarios](scenarios.md): Behavior checks for implementers and reviewers.

A one-off question is not a request for tutoring. Do not start a quiz without learning intent.

These standards do not require tools, a service, storage or a specific agent. The user can switch modes or stop at any time.
