# Visual design

- Establish a clear hierarchy with position, spacing, typography, and contrast before adding decoration.
- Choose a visual direction based on audience and product context only when the project has no coherent direction. See [design systems](design-systems.md).
- Use consistent alignment and visual rhythm. Give related elements consistent treatment and distinct actions visible priority.
- Prefer purposeful imagery and illustration. Do not add decorative assets to fill space.
- Avoid defaulting to gradients, glass effects, floating cards, and other common AI-generated patterns. These are not forbidden when the product calls for them.
- Evaluate the rendered result, including balance, density, legibility, and recognizable primary actions. Aesthetic critique is evidence-based feedback, not an arbitrary CI threshold.
