# Colors and themes

- Use named semantic color tokens for text, surfaces, borders, focus, and status when a design system exists.
- Meet the applicable contrast requirements in [accessibility](accessibility.md). Do not communicate state with color alone.
- Test the themes the project supports, including focused, selected, disabled, error, and hover states where applicable.
- Respect the system theme when the product specification requires it; do not introduce an unsolicited theme.
- Prefer explicit semantic tokens over repeated raw colors. Preserve coherent contrast in overlays and layered surfaces.
