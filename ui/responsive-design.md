# Responsive design

- Identify the supported devices, orientations, display scales, and input methods. Do not assume web breakpoints apply to native apps.
- Verify representative narrow, standard, and wide layouts when those widths are supported. Select risk-based combinations rather than every possible permutation.
- Keep critical tasks available without horizontal clipping, hidden controls, or hover-only interactions.
- Support text enlargement and long content. Preserve the intended reading and focus order when layout changes.
- Validate touch targets where touch is supported, keyboard where keyboard is supported, and pointer affordances where pointer input is supported.
