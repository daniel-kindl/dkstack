# Typography

- Use the project's existing type scale and typefaces. When absent, choose a small coherent scale that distinguishes headings, body text, and secondary content.
- Preserve readability at supported user font sizes and display scaling. Avoid fixed text containers that clip enlarged content.
- Choose line length, line height, and density appropriate to the reading task and platform.
- Do not use type size or color alone to convey essential meaning. Support hierarchy with semantics and grouping.
- Verify long labels, wrapping, dynamic text, and representative localized content.
