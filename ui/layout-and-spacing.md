# Layout and spacing

- Group related information and controls through alignment, proximity, and consistent spacing.
- Reuse project spacing tokens. When absent, define a small spacing scale rather than arbitrary values.
- Avoid fixed dimensions that create clipping, overflow, or unreachable controls under supported content and scaling conditions.
- Prefer intrinsic sizing and adaptable layout over device-specific pixel assumptions.
- Maintain logical reading order and enough separation between distinct controls.
- Inspect dense, sparse, and error states rather than only ideal content.
