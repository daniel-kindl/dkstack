# Skills

Skills are specific capabilities agents should apply when relevant.

## Current skills

- [triage](triage/SKILL.md): Decide which guidelines apply to the current task. Read this first.
- [bootstrap](bootstrap/SKILL.md): Set up conventional commits, branches, semver, strict editorconfig, warnings-as-errors, and deterministic checks.
- [clarify-intent](clarify-intent/SKILL.md): Clarify requirements and domain language before coding.
- [apply-architecture](apply-architecture/SKILL.md): Check design changes against architecture principles.
- [tdd-loop](tdd-loop/SKILL.md): Enforce the red-green-refactor cycle.
- [code-review](code-review/SKILL.md): Review a change on two axes (standards and specification) and give one verdict.
- [write-adr](write-adr/SKILL.md): Create an Architecture Decision Record.
- [write-pr](write-pr/SKILL.md): Write or update a pull request body with evidence and merge risk.
- [writing-check](writing-check/SKILL.md): Apply ASD-STE100 to text.
- [plan-work](plan-work/SKILL.md): Write and keep a feature plan with commit-sized work items.
- [map-work](map-work/SKILL.md): Map an accepted multi-PR objective to child issues and stop before implementation.
- [release](release/SKILL.md): Prepare a release. Link the versioning and safety rules. Do not publish.
