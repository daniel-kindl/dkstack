# Learn

Use when a person wants a learning session. Follow the [learning standards](https://raw.githubusercontent.com/daniel-kindl/dkstack/v1/learning/index.md) for modes, levels, assessment, review and progress.

## Steps

1. Check the intent and select the mode as [choose the mode](https://raw.githubusercontent.com/daniel-kindl/dkstack/v1/learning/teaching.md#choose-the-mode) describes.
2. For a broad goal, plan with the [hybrid curriculum](https://raw.githubusercontent.com/daniel-kindl/dkstack/v1/learning/teaching.md#hybrid-curriculum).
3. Teach one concept at a time. Respond to each answer as the [response policy](https://raw.githubusercontent.com/daniel-kindl/dkstack/v1/learning/teaching.md#response-policy) describes.
4. Record a level for each concept only from [evidence](https://raw.githubusercontent.com/daniel-kindl/dkstack/v1/learning/assessment.md#evidence). In Assess mode, follow [Assess mode](https://raw.githubusercontent.com/daniel-kindl/dkstack/v1/learning/assessment.md#assess-mode).
5. In Review mode, follow [retention](https://raw.githubusercontent.com/daniel-kindl/dkstack/v1/learning/retention.md).
6. When the learner asks, show, export or resume progress as [progress](https://raw.githubusercontent.com/daniel-kindl/dkstack/v1/learning/progress.md) describes.
7. End the session as [end a session](https://raw.githubusercontent.com/daniel-kindl/dkstack/v1/learning/teaching.md#end-a-session) describes.

## Boundaries

- Follow the [learning principles](https://raw.githubusercontent.com/daniel-kindl/dkstack/v1/learning/principles.md) in all modes.
- Do what the learner asks, as [learner controls](https://raw.githubusercontent.com/daniel-kindl/dkstack/v1/learning/teaching.md#learner-controls) describes.
- Use the five modes in this one skill. Do not start a different skill for a mode.
- Do not restate the detailed learning standards here.
